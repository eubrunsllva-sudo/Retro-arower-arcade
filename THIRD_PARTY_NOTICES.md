# Avisos de terceiros

## Etapa 1

Nenhum código, binário, ROM, BIOS ou núcleo de terceiros está incluído nesta versão. A interface e a documentação foram criadas para este projeto. Google Fonts é carregado remotamente pelo CSS do protótipo; a fonte poderá ser removida ou auto-hospedada antes de uma distribuição mais privada/offline.

## Candidatos pesquisados (não incorporados)

- EmulatorJS — https://github.com/EmulatorJS/EmulatorJS — GPL-3.0.
- WebRetro — https://github.com/binbashbanana/webretro — licença e dependências devem ser verificadas na versão escolhida.
- Flycast WASM — https://github.com/nasomers/flycast-wasm — licença, dependências e status experimental devem ser confirmados antes do uso.

Este arquivo deverá ser atualizado para listar versões/commits, licenças de cada core e dependência, modificações e instruções para obter o código-fonte correspondente antes de publicar qualquer build com motores integrados.
